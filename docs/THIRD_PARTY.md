| Project | License | Planned use | Milestone |
|---|---|---|---|
| [ActivityWatch](https://github.com/ActivityWatch) (aw-server-rust, window watchers) | MPL-2.0 | heartbeat merging, window watching | M7 |
| openGym | AGPL-3.0 | workout model, PR/volume logic | M4 |
| Chompass | MIT | adaptive calorie target | M5 |
| Plees Tracker | MIT | sleep statistics | M3 |
| Curbox | GPL-3.0+ | accessibility-based app blocking | M8 |
| free-exercise-db | Unlicense | seed exercise catalogue | M4 |
| Open Food Facts | ODbL (data) | food database, attribution shown in UI | M5 |
| USDA FoodData Central | public domain (data) | food database | M5 |

Each license is re-verified against the upstream repository when code is actually ported.
