# ADR-0003: Local-first sync with an operation log

**Status:** accepted

Every device keeps a full SQLite database and works offline. Each write is an op `{record_id, entity, fields, hlc, device_id, deleted}`, applied locally and queued in an outbox. `POST /sync` pushes unsent ops and pulls server ops after a cursor.

Merge is last-writer-wins per record, ordered by hybrid logical clock (HLC); deletes are tombstones. The same merge function (`hud-sync`) runs on clients and server, and the server materializes ops into typed Postgres tables.

**Consequences:** no merge UI and no field-level CRDTs; concurrent edits to one record keep the later HLC. Property tests must show that reordered or duplicated ops converge to one state.
